# Lumis - App de Serviços de Limpeza

## 📱 Sobre o Aplicativo
O **Lumis** é um aplicativo Android desenvolvido para facilitar a contratação, gerenciamento e agendamento de serviços de limpeza em ambientes **residenciais, empresariais e urbanos**.  
O objetivo é conectar clientes e prestadores de serviço com praticidade, transparência e eficiência diretamente na palma da mão.

---

## 🛠️ Tecnologias Utilizadas
- **Kotlin** → Linguagem principal de desenvolvimento Android
- **Android SDK** → Framework de desenvolvimento mobile
- **Jetpack Compose / XML** → Construção da interface de usuário (UI)

---

## 🤝 Como Contribuir
1. Faça um fork do projeto.
2. Crie uma branch para sua funcionalidade ou correção:  
   - `feature/nome-da-feature`  
   - `bugfix/nome-do-bug`
3. Realize commits descritivos no infinitivo (ex.: `Adiciona tela de login`).
4. Abra um Pull Request descrevendo as alterações.
5. Aguarde a revisão de pelo menos um integrante da equipe antes da aprovação.

---

## ▶️ Como Executar o Projeto Localmente

### Pré-requisitos
- **Android Studio** (versão recente) instalado
- **JDK 17** (ou superior) configurado
- Emulador Android (AVD) configurado ou um dispositivo Android físico com **Depuração USB** ativada

### Passo a passo
1. Clone o repositório:
   ```bash
   git clone https://github.com/fagundessana/LumisApp.git
   ```
2. Abra o **Android Studio**.
3. Selecione a opção **Open an Existing Project** e escolha a pasta do repositório clonado.
4. Aguarde o **Gradle** sincronizar e baixar todas as dependências do projeto.
5. Selecione o emulador ou o seu dispositivo físico no menu superior e clique no botão **Run** (`Shift + F10` ou o ícone ▶️).

# Lumis - Cleaning Services App

## 📱 About the App
**Lumis** is an Android application developed to simplify hiring, managing, and scheduling cleaning services across **residential, commercial, and urban** environments.  
The goal is to connect clients and service providers with convenience, transparency, and efficiency right at their fingertips.

---

## 🛠️ Technologies Used
- **Kotlin** → Primary language for Android development
- **Android SDK** → Mobile development framework
- **Jetpack Compose / XML** → User interface (UI) building

---

## 🤝 How to Contribute
1. Fork the project.
2. Create a branch for your feature or fix:
   - `feature/feature-name`
   - `bugfix/bug-name`
3. Make descriptive commits using the infinitive form (e.g., `Add login screen`).
4. Open a Pull Request describing your changes.
5. Wait for review from at least one team member before merging.

---

## ▶️ How to Run the Project Locally

### Prerequisites
- Recent version of **Android Studio** installed
- **JDK 17** (or higher) configured
- Configured Android Emulator (AVD) or a physical Android device with **USB Debugging** enabled

### Step by Step
1. Clone the repository:
   ```bash
   git clone https://github.com/fagundessana/LumisApp.git
   ```
2. Open **Android Studio**.
3. Select **Open an Existing Project** and navigate to the cloned repository folder.
4. Wait for **Gradle** to sync and download all project dependencies.
5. Select your emulator or connected physical device in the top bar and click the **Run** button (`Shift + F10` or the ▶️ icon).
